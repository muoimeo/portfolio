# Portfolio

Portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Push this folder to GitHub, import the repository in Vercel, and keep the default Next.js settings:

- Build command: `npm run build`
- Output directory: `.next`
- Install command: `npm install`
